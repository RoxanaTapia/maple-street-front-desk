# The board

Open work uses one stage label.

Now is current work. Next comes after the Now work. Later is parked until Now and Next are done.

A priority label sets the order inside a stage. 🔥 p1 is first, then ⬆️ p2, then ➖ p3, then ⬇️ p4. Epic groups smaller issues under a goal.

The filter for current work is:

is:open label:Now

https://github.com/RoxanaTapia/maple-street-front-desk/issues?q=is%3Aopen+label%3ANow
