# Pull request summary

Follow the form in [.github/pull_request_template.md](../../.github/pull_request_template.md). The title is a plain sentence, with no prefix and no emoji. Emojis are only for the section headings. The description starts with Closes #N, then one or two optional plain sentences on why this step comes now, then 📝 What changes, then ⚙️ How it works (two or three plain sentences starting from the risk, then a short "Not covered yet" list), then 🔍 How to review when there is something to try by hand (name the file, two or three commands, one sentence on what comes back; leave it out otherwise), then ✅ Checks. List the acceptance boxes from the issue that this change covers. The checks you run are in [run-checks.md](run-checks.md).
