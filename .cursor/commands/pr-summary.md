# Pull request summary

Follow the form in [.github/pull_request_template.md](../../.github/pull_request_template.md). The hints in that file are the style. Include a Notes section only when there is something the client should look at. Delete that section when there is nothing to add. The checks you run are in [run-checks.md](run-checks.md).
